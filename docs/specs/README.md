# Specs

Permanent system architectures and functional design specifications — the
"what and why" for a change, paired with a plan in `docs/plans/` that
describes the "how" and tracks execution. Specs are not deleted when the work
lands; a completed spec documents the system as designed.

Filename convention: `YYYY-MM-DD-<slug>-design.md` (or `-architecture.md`).

```bash
ls docs/specs/*.md
```
